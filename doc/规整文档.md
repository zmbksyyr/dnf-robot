# DNF Robot

独立 Go 程序，Windows / Linux 共用业务、协议与调度。当前地下城开发采用真人客户端与 Robot 之间的队伍状态包路线。

- [构建与启动](quickstart.md)
- [状态包战斗与验收现状](combat.md)
- [Windows 宿主接口](windows.md)
- [VM 部署](vm.md)
- [Linux 服务端运行要点](linux-server-recipe.md)

`cmd/robot` 负责进程生命周期；`internal/protocol/dnf` 处理游戏和队伍协议；`internal/scheduler` 调度账号；`internal/capability` 提供 PVF、装备、市场等能力。`tools/deploy-launcher` 是独立 Go 模块。

Robot、DNF-Native、DNF-GM 各自维护源码和运行职责。抓包、数据库、密钥及构建产物放在仓库外。
