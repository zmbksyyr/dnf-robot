## 四、③ 双平台

- **代码级**：同一工作树在 Windows 与 Linux（WSL + Go 1.22.5）各跑 `go test ./...`，**45 个包全绿、0 失败**；
- **实机**：Linux 侧曾实测 20 个机器人上线（登录、组队、技能解析与 Windows 一致）；
- **受限**：Linux 版游戏服务端在 WSL 下启动即 SIGSEGV——根因是游戏用高位 brk 预留 132 MB 竞技场，
  把栈挤到 132 KB，首个大栈帧就溢出。已排除：`ulimit -s/-d`、`setarch -3`、`LD_PRELOAD` 的 mallopt 与
  brk 垫片（游戏绕过 libc 直接发系统调用）。需在真实 Linux 主机上运行。
