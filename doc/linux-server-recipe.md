# Linux 服务端运行要点

Robot 的 Linux 入口和信号处理保持原有实现。原游戏服务端由独立环境管理；日常部署见 [VM 说明](vm.md)。

- 直接执行 `df_game_r`，不要把 `ld-linux.so.2` 作为主程序启动：后者曾使 brk 堆靠近栈并导致大栈帧崩溃。
- 配置 ELF interpreter、兼容库目录、`GCONV_PATH` 及服务自身需要的 DP2 preload；逐项核对实际原 ELF / PVF / preload 身份。
- 桥接数据库账号和脚本中的密码必须与实例一致。
- 原桥接线程调用 `exit` 曾触发退出；历史对照环境使用过 `dnf_exit_guard.so`，这属于带 preload 的基线，不能记为未修改环境。
- 本机 Windows 与 WSL 对照栈使用相同端口，顺序运行，避免连接落到另一套服务。

Linux 已有真实登录和进房记录。当前状态包战斗版本的完整实战对照仍待完成，端口监听不代表战斗通过。旧服务端排查只保留这些结论，不恢复已废弃的探针路线。
